# 🔎 AI App Finder

AI App Finder helps you discover AI tools for any task. Describe what you want to do (for example "turn my notes into a presentation" or "learn Python"), optionally pick a category, and the app recommends relevant AI tools with details.

Built with **Python**, **Streamlit** and the **Google Gen AI SDK** (Gemini Flash).

> ⚠️ **Disclaimer:** Recommendations are generated by an AI model. AI tools change quickly, so descriptions, features, pricing and links may be outdated or wrong. Always verify on the official website.

## Features

- Free-text input for your task, problem or goal
- Optional categories: Writing, Coding, Image Generation, Video, Education, Productivity, Data Science
- Choose how many recommendations you want (3-6)
- For each tool: name, description and main features, best use case, pricing type (Free / Freemium / Paid / Unknown), advantages, limitations and an official website link (only shown when the model is confident)
- Loading spinner, input validation and friendly API error messages
- API key kept out of the code (Streamlit secrets or environment variable)

## Setup (run locally)

1. Install **Python 3.10 or newer**.
2. Open a terminal in the project folder and (recommended) create a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Add your API key (see next section), then start the app:

   ```bash
   streamlit run app.py
   ```

   The app opens at http://localhost:8501.

## API key configuration

Get a key from Google AI Studio: https://aistudio.google.com/apikey

**Option A - Streamlit secrets (recommended).** Create the file `.streamlit/secrets.toml` in your project folder:

```toml
GEMINI_API_KEY = "paste-your-key-here"
```

**Option B - environment variable.**

```bash
export GEMINI_API_KEY="paste-your-key-here"      # Windows PowerShell: $env:GEMINI_API_KEY="paste-your-key-here"
```

**Never commit your key to GitHub.** The `.streamlit/secrets.toml` file must stay on your computer only. Either add only the three project files to Git (shown below) or create a `.gitignore` containing `.streamlit/secrets.toml`.

### Optional: choose a different model

The app uses a Gemini Flash model by default (set as `DEFAULT_MODEL` in `app.py`). Model names change over time. If you see a "model not found" error, check the current list at https://ai.google.dev/gemini-api/docs/models and add the name to your secrets:

```toml
GEMINI_MODEL = "gemini-2.5-flash"
```

## Upload to GitHub

1. Sign in at https://github.com and click **New repository**. Name it (for example `ai-app-finder`), choose **Public** (needed for the free Streamlit Community Cloud tier unless you connect a private repo), and create it **without** a README.
2. In your project folder run:

   ```bash
   git init
   git add app.py README.md requirements.txt
   git commit -m "Initial commit: AI App Finder"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/ai-app-finder.git
   git push -u origin main
   ```

   No Git? On the new repository page click **uploading an existing file**, drag in the three files and commit.

## Deploy on Streamlit Community Cloud

1. Go to https://share.streamlit.io and sign in with GitHub.
2. Click **Create app** and choose to deploy from an existing GitHub repository.
3. Select your repository, branch `main`, and main file path `app.py`.
4. Click **Advanced settings** and paste your secret into the **Secrets** box:

   ```toml
   GEMINI_API_KEY = "paste-your-key-here"
   ```

5. Click **Deploy**. The first build installs the packages from `requirements.txt` and takes a few minutes.
6. To change secrets later, open your app's **Settings → Secrets** in the Streamlit dashboard.

## Troubleshooting

| Problem | What to try |
| --- | --- |
| "Gemini API key not found" | Check the secret name is exactly `GEMINI_API_KEY`, then restart or reboot the app. |
| "Request was rejected" | The key may be invalid, restricted, or lack access to the model. Create a new key. |
| "Model was not found" | Set `GEMINI_MODEL` to a model listed in the Gemini API docs. |
| "Too many requests" | You hit a rate or quota limit. Wait a minute, or check your quota in Google AI Studio. |
| Deployment fails on install | Make sure `requirements.txt` is in the repository root and spelled correctly. |

## Limitations

- Information comes from the AI model's training data, not live web search, so it can be outdated or wrong.
- Official links are shown only when the model reports one; open them carefully and confirm the site is the real one.
- Pricing is intentionally general. Check the official pricing page.
